# Projeto Branco

Sistema bancário desenvolvido em Java para estudos de programação orientada a objetos, persistência de dados e autenticação.

## Funcionalidades
- criação de contas
- autenticação de usuários
- saque
- depósito
- transferência

## Tecnologias utilizadas
- Java
- SQLite
- Git/GitHub

## Execução do Projeto

O projeto deve ser executado pela pasta raiz `BANCO/`.

Isso é necessário para garantir o funcionamento correto dos caminhos relativos utilizados pelo SQLite e evitar problemas de duplicidade do banco de dados.

Estrutura esperada:

BANCO/
├── src/
├── data/
├── docs/
├── lib/

O banco de dados será criado automaticamente em:

data/banco.db

## Objetivo

Projeto criado para praticar conceitos de backend e evolução contínua em Java.

Além do aprendizado técnico, o projeto também tem como objetivo desenvolver conhecimentos em:
- arquitetura de software
- organização de projetos
- documentação
- persistência de dados
- versionamento com Git/GitHub
- planejamento de funcionalidades
