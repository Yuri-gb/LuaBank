# Projeto Branco

Sistema bancário desenvolvido em Java para estudos de programação orientada a objetos, persistência de dados e autenticação.

## Funcionalidades
- criação de contas
- autenticação de usuários
- saque
- depósito
- transferência

## Tecnologias utilizadas
- Java
- SQLite
- Git/GitHub

## Objetivo
Projeto criado para praticar conceitos de backend e evolução contínua em Java.
