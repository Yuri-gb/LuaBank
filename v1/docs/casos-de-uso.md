# Casos de Uso

## CU001 - Criar conta

Relacionado ao requisito:
RF001 - Criar conta

### Fluxo principal
1. Usuário acessa o sistema
2. Sistema exibe menu principal
3. Usuário seleciona criar conta
4. Sistema solicita dados do titular
5. Usuário informa os dados
6. Sistema valida as informações
7. Sistema cria a conta
8. Sistema exibe confirmação
